# Uber Booking Analysis | SQL

## Project Overview

Analyzed Uber booking data using MySQL to extract meaningful insights related to ride patterns, customer behavior, driver performance, and revenue generation.

## Dataset

- 100,000 records
- 19 columns
- Customer Table
- Driver Table
- Rides Table

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- JOIN
- Aggregate Functions
- Window Functions
- RANK()
- DENSE_RANK()
- ROW_NUMBER()

## Analysis Performed

- Total Revenue Generated
- Total Rides by Ride Status
- City-wise Ride Count
- Most Used Payment Method
- Rides with High-Rated Drivers
- Customer and Driver Booking Details
- Revenue Earned by Each Driver
- Driver Ranking Based on Total Rides
- Customer Ranking Based on Total Spending
- Rides Ranked by Fare

## Key Skills

SQL | MySQL | Data Analysis | Joins | Aggregations | Window Functions
